# Profile Page

A simple personal profile webpage built using HTML and CSS.

## Project Overview
This project contains a clean, responsive profile page with:
- personal information
- short bio
- skills section
- hobbies
- achievements

## Files
- `profile.html` - main profile page
- `style.css` - styling for the page
- `self.jpeg` - profile image

## How to View
Open `profile.html` in any browser.

Example:

```bash
open profile.html
```
