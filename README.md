# Profile Page

A simple personal profile webpage built using HTML and CSS.

## Project Overview
This project showcases a professional portfolio-style profile with:
- personal summary
- technical skills section
- project experience
- education details
- clean responsive styling

## Files
- `index.html` - main landing page (if used in your project)
- `profile.html` - profile page
- `profile1.html` - alternate profile version
- `profile2.html` - updated profile page
- `style.css` - shared styling for the profile pages

## How to View
Open any HTML file in a browser, for example:

```bash
open profile2.html
```
